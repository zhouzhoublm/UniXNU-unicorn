## 新事实

1. **cpuid**：fastboot `getvar cpuid` → `0x0000043bba5846c1`（64 位）。
   CI secret `UNIXNU_UNIQUE_CHIP_ID` 要求 8 位十六进制，而 `make-pong-adt-ipados18.py` 以 `<Q`（64 位）打包 —— 两者对应 **cpuid 低 32 位 = `ba5846c1`**。这是合理推断而非文档确认；CI 首跑时应对照 ADT 输出核对一次。
2. **马达是 awinic**（`awinic_haptic`，event3），不是 pong 的实现对象；M7 阶段如做震动需另找 AWINIC 驱动，或先不启用。
3. **指纹是 Goodix**（`uinput-goodix`）——XNU 阶段不可用，仅记录。
4. fastboot `kernel:uefi`、`variant:SM_ UFS`、`erase/logical-block-size 0x1000`。

## 安全红线（重申）

- 只用 `fastboot boot`；**禁止** `fastboot flash persist` / `flash all`；modemst1/2(sdf3/sdf4) 永不触碰。
- userdata 尾部 64 GiB 窗口安装前，必须先在 Android 内收缩 data（FBE + f2fs，不能离线 shrink）。
